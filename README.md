## 주요 기능

- React Three Fiber 기반 3D 인터랙티브 효과
- GSAP & Framer Motion 애니메이션
- Turbopack 기반 빠른 개발 환경
- Lucide 아이콘 시스템
- Prettier 코드 포맷팅 자동화

## 실행 방법

```bash
npm install
npm run dev
```

`http://localhost:3000` 에서 확인
